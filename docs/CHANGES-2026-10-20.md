## 1. Top 10 comments for every listed video (YouTube explorer)

**What you can do now**
- Search, or paste links, on the YouTube explorer page, then click **Get top 10 comments**.
  Each video row shows a collapsible list of its top 10 comments (author, date, likes,
  replies, text).
- **Download CSV** gives **one file**: each video's stats plus its top 10 comments in the
  same row (`top_comment_1` … `top_comment_10`). Each cell reads
  `comment text — @author (N likes)`. If comments weren't loaded yet, the button fetches
  them first.
- Videos with comments turned off show "Comments turned off" instead of failing the whole request.
- "Top" means YouTube's own **Top comments** order (not simply most-liked).
- Cost: **1 quota unit per video** (50 videos = 50 of the 10,000 free daily units).
  Asking again within 15 minutes uses no quota (cached).
- The CSV opens correctly in Excel, including emoji and Hindi text.

## 2. Shareable public link (Cloudflare quick tunnel)

**What changed**
- `apps/web/vite.config.ts`: added `allowedHosts: [".trycloudflare.com"]` so the dev server
  accepts visitors arriving through the tunnel link.
- Installed **cloudflared** (you did this via `winget install Cloudflare.cloudflared`).
  It lives at `C:\Program Files (x86)\cloudflared\cloudflared.exe`.

**How to get a link (every time)**
1. Start the database, the API (port 8000) and the website (`npm run dev`, port 5173).
2. In a terminal run:
   ```
   cloudflared tunnel --url http://localhost:5173
   ```
   If it says "not recognized", either restart VS Code completely once, or run
   `$env:Path += ";C:\Program Files (x86)\cloudflared"` first, or use the full path:
   `& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://localhost:5173`
3. Copy the `https://….trycloudflare.com` link from the box it prints and share it.

**Remember**
- The link works only while your laptop is on and all three servers plus the tunnel window are running.
- You get a **new link every time** you restart the tunnel.
- Anyone with the link can sign up and use your YouTube quota.
- Stop sharing: press Ctrl+C in the tunnel window (with nothing selected).
